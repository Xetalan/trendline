Your baseline and where the data lives.

Baseline
Oura ring Desktop only

Pulls in daily steps and workout sessions. Get a personal access token from cloud.ouraring.com → Personal Access Tokens and paste it below. It is encrypted with your Windows credentials, not stored alongside your weigh-ins.

Treadmill sessions come back with no distance — the ring cannot know it. Your typed distance and speed are always kept; syncing again never overwrites them.

Your data

Everything lives in a plain JSON file on this PC. Nothing is uploaded anywhere. A dated backup is written each time the app starts, and the last 14 are kept.

Save backup writes a JSON file holding everything — weigh-ins, workouts and settings. Restore reads one back in. That pair is how you move your history between this PC and your phone.
